## Games that will be added to Xbox Game Pass in January

Xbox Game Pass has announced through a blog post on its official website that it will be adding 5 <strong>new games</strong> to its service library in January. Along with new games, some games will also be leaving the platform. The most <strong>notable game</strong> among the games that will be added to Xbox Game Pass is <strong>Monster Hunter Rise</strong>. The PC version of the game hasn't been released yet and is already available for pre-order, it will be added to Game Pass in the <strong>next few days.</strong>

| Game                                                   | Date       |
|--------------------------------------------------------|------------|
| Persona 3 Portable (Cloud, Console and PC)             | January 19 |
| Persona 4 Golden (Cloud, Console and PC)               | January 19 |
| Monster Hunter Rise (Cloud, Console and PC)            | January 20 |
| Mortal Shell: Enhanced Edition (Cloud, Console and PC) | January 12 |
| Stranded Deep (Cloud, Console and PC)                  | January 12 |

In addition to new releases, there are also games that are leaving Xbox Game Pass. These are as follows:

| Game                                                     | Date       |
|----------------------------------------------------------|------------|
| Danganronpa: Trigger Happy Havoc (Cloud, Console and PC) | January 15 |
| Nobody Saves The World (Cloud, Console and PC)           | January 15 |
| Pupperazzi (Cloud, Console and PC)                       | January 15 |
| The Anacrusis (Game Preview) (Cloud, Console and PC)     | January 15 |
| We Happy Few (Cloud, Console and PC)                     | January 15 |
| Windjammers 2 (Cloud, Console and PC)                    | January 15 |

In addition to these, it has also been announced that a biome update has been released for Valheim: Mistlands. This update includes new features for building and combat mechanics.
