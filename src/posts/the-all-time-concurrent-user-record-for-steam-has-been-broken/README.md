According to SteamDB, the all-time highest number of concurrent users on Steam was reached early today at 33,078,963, though many of these were logged in but not actively using Steam. The number of active users on Steam at the moment is 10,283,568.

These numbers for Steam have been steadily increasing since the start of the pandemic in 2020. The peak, which was just under 30 million in March of last year, broke the significant barrier of 30,049,264 in October.

## Which games are behind Steam's record?

Some of the games that are behind not only this record but also previous records on Steam, the gathering place for PC gamers, include CS:GO and Dota 2. In addition to these two games, Goose Goose Duck, PUBG, Apex Legends, Lost Ark, GTA 5, Rust, Modern Warfare, and Wallpaper Engine also made it into the top 10, in that order.
