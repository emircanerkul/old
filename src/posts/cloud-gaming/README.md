## What is cloud gaming?

Cloud gaming is basically playing a game on a server that you don't own. With this **technology**, you can play newly released high graphic games without waiting to download and install. You can directly connect to a remote computer and immediately jump into the game without any time-wasting.

## Why should you use cloud gaming services?

If you don't have a powerful machine and the latest high-priced graphic cards you can use these services. With these services of course you don't have to download games. Even you can play the latest games like *cyberpunk 2077* or Battlefield™ 2042 on your web browser without downloading any software. When you click to play button you'll start a game in less than a minute and any devices (it depends on which cloud service do you use).

## What types of cloud gaming services is there?

There are basically two types of **cloud gaming** services. One of you need to pay for games too for playing, the other one and this one is my favorite, you don't need to pay for games too. On this option cloud gaming service offer you a game library that you can freely select and play immediately without any additional cost. Also, there are hybrid options, if you wanna play more and popular games you need to pay more monthly fees.

## Who are these cloud game providers?

* One of the cheapest ones and my favorite one is **GeForce Now**. On GeForce Now there are lots of free games like Path of Exile, Dota 2, Destiny 2, League of Legends, Warframe, Fortnite, and much more. Also supports lots of games and game libraries like Steam, Epic Games, and Ubisoft. And recently they supported some EA games too.
* Other my favorite is **Amazon Luna**. This service newly arrived but I believe Luna will be taken to lead cloud gaming service.
* **SHADOW** is not just cloud game providers it's also called cloud computing providers. With this service, you can do 3D or Architectural works that need high GPU power on the cloud.
* Boosteroid, Vortex, Playkey, **Paperspace**, Playhatch, and GameStream just other cloud game providers.
